## 16. Применение (интерпретация)

В [[#15. Цепочка одним взглядом|§15]] цепочка сведена, но порядка, в котором её проходят на конкретном случае, нет. Собрать этот порядок — уже не вывод, а применение. В этом разделе вывод кончается там, где предложение помечено «Интерпретация:». Новых закономерностей и техник раздел не вводит. Каждое правило раздела ссылается назад на объект, из которого оно получено. Геополитическим здесь называем вопрос анализа о действиях государств и других сторон международных отношений. Частный случай: анализ по геополитическому вопросу получается подстановкой в цепочку геополитического вопроса на место вопроса анализа и государства или другой стороны международных отношений на место актора. Поэтому всё, что установлено в цепочке для любого вопроса и любого актора, применяется к анализу по геополитическому вопросу подстановкой, без новой логики. Однако, по Heuer (1999, гл. 11), во время пограничных столкновений 1969 года специалисты ЦРУ по СССР были склонны принимать версии советского режима об истории и прохождении границы. %%src: Hm 2652%% Поскольку версия советского режима, которая была у этих специалистов во время пограничных столкновений 1969 года, — сообщение о реальности, которое было у них в это время, то эта версия — их сведение ([[#1.1 Сведения и информация|§1.1]]). Вопрос этих специалистов о пограничных столкновениях 1969 года — вопрос анализа о действиях государств, то есть геополитический вопрос; значит, их анализ — анализ по геополитическому вопросу. По Heuer (там же), по этому вопросу специалисты по СССР считали, что китайская сторона провоцирует, а специалисты по Китаю — что китайская сторона лишь отвечает на советскую надменность. %%src: Hm 2652%% Версия советского режима об истории и прохождении границы — ответ советского режима, одной из сторон международных отношений, на этот вопрос. Следовательно, среди сведений в анализе по геополитическому вопросу бывают и такие, в которых одна из сторон даёт свой ответ на вопрос. Для любых аналитика A, даты D, вопроса Q и актора X, который является государством или другой стороной международных отношений, трактовка стороны X по вопросу Q у аналитика A на дату D — это сведение аналитика A на дату D, в котором содержится ответ актора X на вопрос Q. Имя «трактовка стороны» введено в этом тексте; в книгах термина нет. Трактовки сторон уже несут готовый ответ, а цепочка даёт способы попытаться опровергнуть ответ на вопрос ([[#5.3 Отбор сведений|§5.3]]), но не выбирает ответ, с которого начинается попытка опровергнуть ответ на вопрос. Ответ на вопрос принимается по умолчанию — то есть попытка опровергнуть ответ на вопрос начинается с него, а другие ответы на этот вопрос сравнивают с ним. Трактовка стороны принимается по умолчанию — то есть ответ этой трактовки стороны принимается по умолчанию. Трактовки сторон есть, а какая из них принимается по умолчанию, не установлено.

Предпосылка (далее — предпосылка радикальной нейтральности): ни одна трактовка стороны по вопросу анализа не принимается по умолчанию; ответ, который даёт любая трактовка стороны по вопросу анализа, входит в анализ лишь как одна из гипотез ([[#8.5 Analysis of Competing Hypotheses (ACH)|§8.5]]) или как один из сценариев ([[#14.1 Сценарий и веер|§14.1]]); ответ, который аналитик формулирует при своей рамке по этому вопросу ([[#9.1 Рамка|§9.1]]), тоже не принимается по умолчанию; логику каждой стороны аналитик реконструирует, не принимая её. Имя «предпосылка радикальной нейтральности» введено в этом тексте; в книгах такого термина нет. Без предпосылки радикальной нейтральности ответ, с которого начинается попытка опровергнуть ответ на вопрос, остаётся не выбранным, и трактовка одной из сторон может быть принята по умолчанию; тогда ответы трактовок остальных сторон не входят в набор гипотез ([[#8.5 Analysis of Competing Hypotheses (ACH)|§8.5]]) или в веер ([[#14.1 Сценарий и веер|§14.1]]) наравне с ответом этой трактовки. Без части о рамке самого аналитика точкой отсчёта остаётся ответ, который аналитик формулирует при своей рамке по этому вопросу, и ответы трактовок сторон сравнивают с этим ответом, а не держат наравне с ним. Без части о логике сторон логику стороны аналитик принимает, а не реконструирует, и ничто не требует реконструировать логику каждой стороны с помощью Red Hat Analysis ([[#9.3 Red Hat Analysis|§9.3]]). Предпосылка радикальной нейтральности не выводится из цепочки; цепочка лишь даёт средства её выполнить. Предпосылка радикальной нейтральности задана, но процедура для случая не собрана.

Каждый шаг ниже ссылается на подраздел, в котором определён его объект, и ничего сверх этого объекта и предпосылки радикальной нейтральности не утверждает. Интерпретация: для вопроса о случившемся событии процедуру ([[#6.4 Рассуждение в одной голове и экстернализация|§6.4]]) собираем из техник, уже введённых в цепочке. Разбор случившегося события — процедура из следующих шагов:

1. Выписать допущения, на которых держится суждение, и поставить каждое под вопрос — Key Assumptions Check ([[#8.3 Key Assumptions Check (KAC)|§8.3]]).
2. Составить набор конкурирующих гипотез по вопросу ([[#8.5 Analysis of Competing Hypotheses (ACH)|§8.5]]), включив в него ответ, который даёт трактовка каждой стороны, как гипотезу (по предпосылке радикальной нейтральности) и гипотезу обмана, когда это уместно по условиям Deception Detection ([[#8.12 Предпосылки ACH|§8.12]]; правило 1 ниже).
3. Построить матрицу ACH ([[#8.6 Матрица ACH|§8.6]]), искать данные матрицы ACH, диагностичные относительно набора гипотез ([[#8.7 Диагностичность|§8.7]]), и ранжировать гипотезы по Inconsistency Score ([[#8.8 Inconsistency Score|§8.8]]).
4. Проверить чувствительность порядка гипотез по счёту несогласий ([[#8.10 Чувствительность|§8.10]]): если этот порядок чувствителен, перепроверить те данные матрицы ACH и надёжность тех источников, от которых зависит порядок гипотез.
5. Реконструировать логику каждой стороны — как ситуацию видит она — с помощью Red Hat Analysis ([[#9.3 Red Hat Analysis|§9.3]]), подставляя эту сторону на место целевого актора.
6. Выразить суждение оценкой ([[#10.3 Оценка и прогноз|§10.3]]), приписав исходам числовую вероятность или диапазон ([[#10.4 Число вместо слова|§10.4]]), а не словесную вероятность без числа.
7. Записать индикаторы гипотез набора ([[#8.11 Индикатор|§8.11]]) и пересмотреть ранжирование гипотез, когда на дату наблюдения индикатор гипотезы набора есть.
8. Обновлять оценку байесовским обновлением по каждому новому относительно неё сведению ([[#12.7 Байесовское обновление|§12.7]]), а величину шага выбирать по условиям, при которых оправданы малые шаги ([[#12.9 Малые шаги и их условия|§12.9]]).

Эта процедура закрывает вопрос о случившемся событии. Но вопрос анализа может касаться и того, как к сроку сложится ситуация. Поскольку ситуация к сроку может сложиться по-разному, суждение о ней держат не набором гипотез о случившемся, а веером сценариев ([[#14.1 Сценарий и веер|§14.1]]). Шагов для веера разбор случившегося события не даёт.

Интерпретация: для вопроса о том, как к сроку сложится ситуация, процедуру собираем из техник сценариев. Процедура прогнозирования развития ситуации — процедура из следующих шагов:

1. Зафиксировать вопрос и горизонт сценариев ([[#14.1 Сценарий и веер|§14.1]]) и сопоставить горизонт с пределом предсказуемости для аналитика и вопроса ([[#14.5 Вероятности сценариев и предел предсказуемости|§14.5]]).
2. Выделить ключевые драйверы аналитика по этому вопросу от даты этого шага к горизонту сценариев ([[#14.2 Ключевой драйвер|§14.2]]), отыскивая их по перечню областей STEMPLES+ ([[#14.3 Как строится веер|§14.3]]).
3. Построить веер — базовый сценарий, альтернативные сценарии и wild card — с помощью техники Cone of Plausibility ([[#14.4 Конус правдоподобия и условия закономерности|§14.4]]), включив в веер как сценарий ответ, который даёт трактовка каждой стороны о том, как к сроку сложится ситуация (по предпосылке радикальной нейтральности), и реконструировав логику каждой стороны с помощью Red Hat Analysis ([[#9.3 Red Hat Analysis|§9.3]]), подставляя эту сторону на место целевого актора.
4. По Pherson & Heuer (2021, гл. 9; гл. 11, §11.1), сценарии не предсказывают, как пойдут события. %%src: Pm 5534; Pm 7625; Pm 5117%% Однако по посылке [[#14.5 Вероятности сценариев и предел предсказуемости|§14.5]] сценариям веера в этом тексте приписывают вероятности сценариев. Интерпретация: если горизонт ближе предела предсказуемости для аналитика и вопроса (шаг 1), дать каждому сценарию вероятность сценария — числом или диапазоном ([[#10.4 Число вместо слова|§10.4]]). Интерпретация: если горизонт дальше предела предсказуемости для аналитика и вопроса, держать веер без вероятностей сценариев, как подготовку к неожиданному, а вероятности давать малым вопросам о значениях ключевых драйверов и о том, есть ли индикаторы сценариев на более близкие даты наблюдения ([[#14.5 Вероятности сценариев и предел предсказуемости|§14.5]]).
5. Задать индикаторы на каждый сценарий веера ([[#14.6 Индикаторы сценариев и обновление|§14.6]]).
6. Вести мониторинг индикаторов сценариев и по индикаторам сценариев, которые на дату наблюдения есть, обновлять вероятности сценариев байесовским обновлением ([[#12.7 Байесовское обновление|§12.7]]). Если вероятностей сценариев нет (шаг 4, вторая ветвь), индикатор сценария, который на дату наблюдения есть, показывает, в состояние какого сценария веера начинает складываться ситуация ([[#14.6 Индикаторы сценариев и обновление|§14.6]]), а байесовским обновлением обновляют вероятности малых вопросов шага 4.

Обе процедуры по построению выполняют предпосылку радикальной нейтральности: часть о трактовках — на шагах 2–3 разбора случившегося события и шаге 3 процедуры прогнозирования развития ситуации, части о логике сторон и о рамке аналитика — на шаге 5 разбора случившегося события и шаге 3 процедуры прогнозирования развития ситуации. В разборе случившегося события ответ, который даёт трактовка каждой стороны, входит в анализ как одна из гипотез набора (шаги 2–3). В процедуре прогнозирования развития ситуации ответ, который даёт трактовка каждой стороны о том, как к сроку сложится ситуация, входит в анализ как один из сценариев веера (шаг 3). Логику каждой стороны в обеих процедурах реконструирует Red Hat Analysis (шаг 5 разбора случившегося события, шаг 3 процедуры прогнозирования развития ситуации). Red Hat Analysis — техника смены рамки ([[#9.2 Механизм смены рамки|§9.2]]): шаги Red Hat предписывают ставить вопрос с позиции, отличной составляющей позиции «чьими глазами» ([[#9.3 Red Hat Analysis|§9.3]]). Поэтому на шаге 5 разбора случившегося события и на шаге 3 процедуры прогнозирования развития ситуации вопрос ставится с позиции, в которой поведение каждой стороны объясняется логикой самой этой стороны. Значит, на этих шагах ответ, который аналитик формулирует при своей рамке по этому вопросу, не принимается по умолчанию. Следовательно, предпосылка радикальной нейтральности выполняется на шагах 2–3 и 5 разбора случившегося события и на шаге 3 процедуры прогнозирования развития ситуации. Однако нужны ли остальные шаги обеих процедур — можно ли без потерь выкинуть часть шагов или сразу выразить суждение оценкой с числовой вероятностью, — не установлено.

Довод против сокращения строится на посылках из цепочки. Течение искажения недоступно самонаблюдению аналитика ([[#6.2 Недоступность интроспекции|§6.2]]). Против какой формы ошибки стоит каждое семейство техник, показывает карта форм ошибки ([[#7.4 Шесть семейств и карта форм ошибки|§7.4]]). Шагом процедуры, стоящим против формы ошибки, называем шаг процедуры, который берёт технику, стоящую против этой формы ошибки ([[#7.4 Шесть семейств и карта форм ошибки|§7.4]]). Интерпретация: если аналитик выкидывает шаг процедуры, который ему кажется лишним, то решает, что этот шаг лишний, тот же аналитик, течение искажений которого его самонаблюдению недоступно. Интерпретация: поэтому выкинутым может оказаться как раз тот шаг процедуры, техника которого стоит против той формы ошибки, которой пользуется этот аналитик. Интерпретация: поэтому шаги процедур, которые берут технику, не выкидываются. У довода против того, чтобы сразу выразить суждение оценкой с числовой вероятностью, посылка другая: точность проверяется на потоке оценок, а не на отдельной оценке ([[#11.1 Поток оценок|§11.1]]). Поэтому по отдельной оценке, каким бы определённым ни выглядело её число, точность оценок аналитика не проверить. Однако, поскольку до шага, на котором суждение выражается оценкой с числовой вероятностью, самой этой оценки ещё нет, то до этого шага попытаться опровергнуть можно только суждение, из которого эта оценка строится. В разборе случившегося события суждение, из которого строится оценка, держится на допущениях (шаг 1), гипотезах набора (шаги 2–4) и рамке аналитика по этому вопросу (шаг 5). Интерпретация: оценка с числовой вероятностью, построенная без попытки опровергнуть суждение, из которого она строится, чётка лишь на вид: её строит суждение, которое никто не пытался опровергнуть. Интерпретация: поэтому в разборе случившегося события оценка с числовой вероятностью (шаг 6) идёт после попытки опровергнуть суждение, из которого она строится (шаги 1–5). По Pherson & Heuer (2021, гл. 9), построение сценариев может помочь аналитику предвидеть неожиданное, заставляя его оспаривать допущения. %%src: Pm 5541%% Поэтому в процедуре прогнозирования развития ситуации оспаривать допущения может построение веера (шаг 3). Однако сопоставления гипотез набора со сведениями, как в ACH ([[#8.5 Analysis of Competing Hypotheses (ACH)|§8.5]]), перед вероятностями сценариев (шаг 4) в процедуре прогнозирования развития ситуации нет. Поскольку в этой процедуре суждение, из которого строятся вероятности сценариев, перед шагом 4 со сведениями не сопоставлено, то вероятности сценариев в ней строятся из суждения, не сопоставленного со сведениями. На этом месте в процедуре прогнозирования развития ситуации стоит другое: вероятности сценариям дают, лишь если горизонт ближе предела предсказуемости для аналитика и вопроса (шаг 1), а дальше предела предсказуемости для аналитика и вопроса числовую вероятность дают не сценариям, а малым вопросам о ключевых драйверах и индикаторах сценариев (шаг 4). Интерпретация: условие о пределе предсказуемости для аналитика и вопроса решает, чему дают числовую вероятность, но сопоставления со сведениями суждения, из которого строится оценка, не заменяет; поэтому для процедуры прогнозирования развития ситуации довод против того, чтобы сразу выразить суждение оценкой с числовой вероятностью, в части сопоставления со сведениями остаётся открытым. Интерпретация: шаги процедур, которые берут технику, не выкидываются, и в разборе случившегося события оценка с числовой вероятностью идёт после попытки опровергнуть суждение, из которого она строится. Но по карте форм ошибки ([[#7.4 Шесть семейств и карта форм ошибки|§7.4]]) каждое семейство стоит против своих форм ошибки, а техники каких семейств берут шаги процедур и почему именно их, не сказано.

По Pherson & Heuer (2021, гл. 1), структурированные техники делятся на шесть семейств ([[#7.4 Шесть семейств и карта форм ошибки|§7.4]]). По их же отнесению (2021, гл. 7–9), Key Assumptions Check и ACH — техники семейства Diagnostic, Red Hat Analysis — семейства Reframing ([[#9.2 Механизм смены рамки|§9.2]]), а Key Drivers Generation, Cone of Plausibility и Indicators Generation — семейства Foresight. Проверка чувствительности (шаг 4 разбора случившегося события) — шаг ACH ([[#8.10 Чувствительность|§8.10]]), а запись индикаторов (шаг 7 разбора случившегося события и шаг 5 процедуры прогнозирования развития ситуации) — техника Indicators Generation ([[#8.11 Индикатор|§8.11]], [[#14.6 Индикаторы сценариев и обновление|§14.6]]). Шаг 1 процедуры прогнозирования развития ситуации задаёт вопрос и горизонт, а шаги 6 и 8 разбора случившегося события и шаги 4 и 6 процедуры прогнозирования развития ситуации выражают суждение оценкой и ведут её ([[#10.4 Число вместо слова|§10.4]], [[#12.7 Байесовское обновление|§12.7]]). Предпосылка: шаг 1 процедуры прогнозирования развития ситуации, шаги 6 и 8 разбора случившегося события и шаги 4 и 6 процедуры прогнозирования развития ситуации не берут структурированную технику ни одного из шести семейств. Без этой предпосылки неизвестно, берут ли эти шаги технику какого-либо семейства, и число семейств, из которых шаги процедур берут техники, не определено. Поскольку шаги 1–4 разбора случившегося события берут технику Diagnostic, шаг 5 разбора случившегося события и шаг 3 процедуры прогнозирования развития ситуации — технику Reframing, шаг 7 разбора случившегося события и шаги 2, 3 и 5 процедуры прогнозирования развития ситуации — техники Foresight, а остальные шаги техник не берут, то шаги процедур берут техники трёх семейств из шести. Несущим здесь называем семейство структурированных техник, техники которого берут шаги процедур этого раздела. Имя «несущие семейства» введено в этом тексте; в книгах такого выделения нет. Следовательно, несущие семейства — Diagnostic, Reframing и Foresight. Интерпретация: процедуры берут именно семейства Diagnostic, Reframing и Foresight, потому что каждое из них выполняет свою часть работы в анализе по геополитическому вопросу. Интерпретация: если трактовка стороны принята по умолчанию, то ответ этой трактовки становится ведущей гипотезой аналитика, и Confirmation Bias ([[#5.3 Отбор сведений|§5.3]]) направляет поиск сведений на подтверждение этого ответа. Главная мишень — Confirmation Bias ([[#7.5 Главная мишень|§7.5]]). По Pherson & Heuer (2021, гл. 7), против Confirmation Bias стоят техники семейства Diagnostic. %%src: Pm 1473%% В ACH ответ, который даёт трактовка стороны, становится одной из гипотез и сопоставляется со сведениями наравне с остальными. Интерпретация: поэтому Diagnostic считаем главным средством выполнить предпосылку радикальной нейтральности. Reframing даёт реконструкцию логики каждой стороны без принятия этой логики. Foresight даёт техники шагов 2, 3 и 5 процедуры прогнозирования развития ситуации. Интерпретация: техники остальных семейств берутся по мере надобности. По Pherson & Heuer (2021, гл. 10), техники Decision Support помогают решающему выбрать действие. По ним же, эти техники дают и рамку для анализа того, почему и как руководитель, группа или страна приняли решение или скорее всего его примут. %%src: Pm 6726–6734%% Интерпретация: поэтому в анализе по геополитическому вопросу Decision Support служит суждению о действиях стороны по мере надобности. Несущим Decision Support не является, поскольку ни один шаг процедур не берёт его технику. Каждое из трёх несущих семейств стоит против своих форм ошибки ([[#7.4 Шесть семейств и карта форм ошибки|§7.4]]), а что угрожает анализу по геополитическому вопросу на шагах, техники которых берутся из несущих семейств, не сказано.

Интерпретация: на шагах, техники которых берутся из несущих семейств, анализу по геополитическому вопросу угрожают: на шагах Diagnostic (шаги 1–4 разбора случившегося события) — дезинформация, которая эксплуатирует Confirmation Bias и Vividness Bias, убедительная история, на которой действуют Evidence Acceptance Bias и Vividness Bias, и доверие к комментатору по его известности; на шагах Diagnostic и Reframing (шаги 2 и 5 разбора случившегося события) — объяснение действий государства «природой режима», в котором действует Fundamental Attribution Error; на шаге Reframing (шаг 5 разбора случившегося события) — Mirror Imaging. Интерпретация: на шагах с числом, которые техники ни одного из шести семейств не берут, угрожает округление до нуля малой субъективной вероятности исхода, у которого большие последствия ([[#10.5 Субъективная вероятность|§10.5]]). Против каждой угрозы ниже стоит правило при её шаге; в заголовке правила названо семейство техники этого шага, и каждое правило ссылается назад на объект, из которого оно получено.

1. **Шаги 1–4 разбора случившегося события (Diagnostic) — дезинформация.** По Pherson & Heuer (2021, гл. 2, §2.5), распространители цифровой дезинформации знают, что массовым восприятием легче всего управлять, эксплуатируя прочно укоренившиеся когнитивные ограничения. %%src: Pm 1119–1123%% По ним же (там же), Confirmation Bias и Vividness Bias — два из самых сильных искажений, которые распространители дезинформации эксплуатируют ([[#5.8 Правдоподобие исходов|§5.8]]). %%src: Pm 1127%% По Pherson & Heuer (2021, гл. 7, §7.8), мерило хорошей операции обмана — то, насколько она эксплуатирует когнитивные искажения своей аудитории. %%src: Pm 3886%% По ним же, аналитику следует настораживаться, когда сведения сильно играют на его собственные известные искажения и предпочтения. %%src: Pm 3906%% Интерпретация: аналитик, который ведёт анализ по геополитическому вопросу, — возможная мишень чужого воздействия через его искажения со стороны любой из сторон, поэтому сведения в анализе по геополитическому вопросу могут быть подброшены. Интерпретация: дезинформация, которая дошла до аналитика, — то есть подброшенные сведения среди сведений этого аналитика ([[#8.12 Предпосылки ACH|§8.12]]). По Pherson & Heuer (2021, гл. 7, §7.8), аналитику следует регулярно рассматривать возможность того, что противник вводит его в заблуждение, и отвергнуть её только потому, что следов обмана нет, нельзя. %%src: Pm 3898%% Однако, по ним же, если допустить, что любое из полученных сведений может быть обманным, под вопросом оказываются все сведения, и это может парализовать анализ. %%src: Pm 3880%% По Heuer (цит. по Pherson & Heuer, там же), аналитик, который ждёт обмана, часто находит его следы и там, где обмана нет. %%src: Pm 3860%% По Pherson & Heuer (там же), чтобы анализ не был парализован, аналитику нужны средства определить, когда опасаться обмана уместно. %%src: Pm 3880%% Условия, при которых опасаться обмана стоит, они перечисляют в Deception Detection ([[#8.12 Предпосылки ACH|§8.12]]): вывод держится на одном критическом сообщении; ключевые сведения пришли в критический момент; принять сведения значит потратить или перебросить большие ресурсы либо сменить ключевое допущение или ключевое суждение; у возможного обманщика может быть канал обратной связи; источник сомнителен; у возможного обманщика есть история обмана. %%src: Pm 3866–3874%% По ним же (там же), когда такие условия складываются, аналитик оценивает возможность обмана по четырём чек-листам: MOM (Motive, Opportunity, and Means; мотив, возможность и средства), POP (Past Opposition Practices; прошлая практика противника), MOSES (Manipulability of Sources; уязвимость источников к манипуляции) и EVE (Evaluation of Evidence; оценка данных). %%src: Pm 3898; Pm 3932–3960%% По Pherson & Heuer (2021, гл. 7, §7.6, шаг 1), гипотеза обмана вносится в набор, когда это уместно ([[#8.12 Предпосылки ACH|§8.12]]). %%src: Pm 3704, 3913%% Интерпретация: поэтому на шаге 2 каждого разбора случившегося события по геополитическому вопросу аналитик проверяет условия Deception Detection. Интерпретация: если выполнено хотя бы одно из этих условий, аналитик оценивает возможность обмана по чек-листам MOM, POP, MOSES и EVE и вносит гипотезу обмана в набор, когда эта оценка показывает, что это уместно. По Pherson & Heuer (2021, гл. 2, §2.5), одного осознания своей уязвимости к дезинформации недостаточно. По ним же, среди техник, особенно действенных против дезинформации, — Key Assumptions Check ([[#8.3 Key Assumptions Check (KAC)|§8.3]]), ACH ([[#8.5 Analysis of Competing Hypotheses (ACH)|§8.5]]), Premortem Analysis ([[#9.6 Premortem Analysis|§9.6]]) и Structured Self-Critique ([[#9.7 Structured Self-Critique|§9.7]]). %%src: Pm 1129–1138%% Интерпретация: поэтому шаги 1–4 в разборе случившегося события по геополитическому вопросу служат и защитой от дезинформации. По определению Persistence of Discredited Evidence ([[#5.5 Опровергнутая опора|§5.5]]), аналитик, который пользуется этой стратегией, сохраняет на дату D₁ впечатление по вопросу на более раннюю дату D, не пересматривая это впечатление по тому, что его сведения на дату D₁ говорят о сведениях, на которые это впечатление опирается. Интерпретация: признание подброшенного сведения ложным не обязательно отменяет впечатление, которое на нём построено. Интерпретация: поэтому дезинформация может сохранять действие и после того, как подброшенное сведение признано ложным. Интерпретация: поэтому на шаге 4 признание сообщений источника ложными требует явно пересмотреть надёжность этого источника, его строки в матрице ACH и ранжирование гипотез ([[#8.10 Чувствительность|§8.10]]), а не только пометить источник как ненадёжный.
2. **Шаги 2 и 5 разбора случившегося события (Diagnostic и Reframing) — «природа режима».** По определению в [[#5.6 Объяснение причин|§5.6]], Fundamental Attribution Error — стратегия аналитика объяснять поведение актора диспозицией этого актора, недооценивая роль обстановки этого актора в этом поведении. По Heuer (1999, гл. 11), сторонние наблюдатели советского вторжения в Афганистан, согласно теории атрибуции, были бы склонны приписать его агрессивной и экспансионистской природе советского режима (там же). %%src: Hm 2650%% Объяснение «природой режима» называет причиной поведения государства то, что лежит в самом этом государстве. Поэтому, при подстановке государства на место актора, это объяснение — объяснение поведения государства диспозицией этого государства ([[#5.6 Объяснение причин|§5.6]]). По Heuer (1999, гл. 11), внешние причины поведения — стимулы и ограничения, требования роли, социальное давление и другие силы, над которыми актор мало властен ([[#5.6 Объяснение причин|§5.6]]). %%src: Hm 2608%% Ограничения обстановки актора — для любого актора — это те причины поведения этого актора из обстановки этого актора, которые сужают выбор действий этого актора. Обстановка актора определена в [[#5.6 Объяснение причин|§5.6]]. По Heuer (там же), при относительно полных сведениях об ограничениях обстановки аналитик может судить точно, а без них чаще ошибается, объясняя поведение актора диспозицией этого актора. %%src: Hm 2640%% По Heuer (там же), неприязнь к Советскому Союзу и нехватка сведений об ограничениях обстановки, какими их видели сами советские руководители, вероятно, усилили бы у наблюдателей склонность объяснять вторжение природой режима. %%src: Hm 2650%% Интерпретация: нехватка сведений об ограничениях обстановки государства, какими их видит само это государство, может так же усиливать склонность объяснять действия любого государства «природой режима». Интерпретация: поэтому прежде чем объяснять действия государства «природой режима», аналитику нужно проверить ограничения обстановки этого государства. Интерпретация: поэтому «природа режима» входит в набор на шаге 2 как одна из гипотез, а не служит исходной точкой. Как ограничения обстановки этого государства видит само это государство, реконструирует шаг 5 (Red Hat Analysis). Советские руководители, по разбору Heuer на основе теории атрибуции, видели бы вторжение в Афганистан как ответ на требования обстановки в Южной Азии, в том числе на угрозу того, что исламский национализм из Ирана и Афганистана распространится в Советский Союз. %%src: Hm 2642%%
3. **Шаг 3 разбора случившегося события (Diagnostic) — убедительная история.** По Evidence Acceptance Bias ([[#5.3 Отбор сведений|§5.3]]) аналитик принимает свои сведения за факт потому, что они складываются в связную историю. Связность же не влечёт истинности, потому что непротиворечивая выдумка тоже связна (там же). По Vividness Bias ([[#5.8 Правдоподобие исходов|§5.8]]) аналитик оставляет без рассмотрения исходы и гипотезы, кроме исхода самого яркого для него сценария. Интерпретация: яркость и эмоциональная убедительность, как и связность, — свойства самой истории, а не её согласия с данными; поэтому, как и связность, истинности они не влекут. Интерпретация: отсюда правило — ни яркость и эмоциональная убедительность истории, ни её связность не довод в пользу её истинности. Интерпретация: поэтому в матрице ACH на шаге 3 ранжирование решает Inconsistency Score гипотезы ([[#8.8 Inconsistency Score|§8.8]]), а не то, насколько складно гипотеза звучит.
4. **Шаг 4 разбора случившегося события (Diagnostic) — яркий комментатор.** По Tetlock & Gardner (2015, гл. 3), в EPJ чем известнее был эксперт, тем менее точны по расхождениям были его прогнозы ([[#13.3 Почему ёж проигрывает и почему ежи на виду|§13.3]]). По ним же, медиа ищут ежей, потому что ежи рассказывают простые ясные истории и говорят уверенно (там же). Прогнозы лис, по результатам EPJ, в среднем точнее по расхождениям прогнозов ежей ([[#13.2 Ёж и лиса|§13.2]]). Интерпретация: стиль комментатора, который подводит любой вопрос под одно и то же общее утверждение, читаем как ежиный стиль ([[#13.2 Ёж и лиса|§13.2]]), а прогнозы ежей по результатам EPJ в среднем менее точны по расхождениям. Однако средняя точность прогнозов ежей суждения о точности прогнозов конкретного комментатора не даёт. Комментатор, который даёт прогнозы, — прогнозист ([[#13.1 Что решает точность помимо инструментов|§13.1]]), то есть аналитик. Поэтому суждение о точности прогнозов конкретного комментатора даёт только поток его оценок ([[#11.1 Поток оценок|§11.1]]). По Tetlock & Gardner (2015, гл. 1), точность прогнозов известных комментаторов, как правило, никто строго не проверял, а медиа выдают прогнозы, даже не спрашивая, насколько хороши прогнозисты. %%src: Tm 185%% По ним же, за редкими исключениями комментаторы попадают на экраны не за доказанное умение прогнозировать, а за умение убедительно и уверенно рассказать историю. %%src: Tm 201%% По Tetlock & Gardner (2015, гл. 6), по данным исследований, люди больше доверяют уверенным финансовым советникам, чем менее уверенным, даже при одинаковой истории прогнозов. %%src: Tm 1548%% Tetlock & Gardner (2015, гл. 12) надеются, что потребители прогнозов начнут спрашивать комментаторов, как сбылись их прошлые прогнозы, и перестанут принимать ответы из одних историй и регалий. %%src: Tm 2769%% Интерпретация: поэтому на шаге 4 о точности прогнозов конкретного комментатора судят только по потоку его оценок, а без такого потока ни известность, ни категоричность веса его прогнозам не прибавляют.
5. **Шаг 5 разбора случившегося события (Reframing) — Mirror Imaging.** Mirror Imaging — стратегия аналитика объяснять поведение актора и судить на дату о будущих относительно этой даты действиях этого актора, исходя из того, что этот актор думает, ценит и воспринимает мир так же, как этот аналитик ([[#5.6 Объяснение причин|§5.6]]). По Pherson & Heuer (2021, гл. 8), неосознанное допущение, что другие страны и их лидеры поступят так же, как поступили бы мы в сходных обстоятельствах, — форма Mirror Imaging и одна из самых частых причин провалов разведки (там же). %%src: Pm 4242%% Поскольку Mirror Imaging определена для любого актора ([[#5.6 Объяснение причин|§5.6]]), то по подстановке в начале раздела она может действовать в анализе по любому геополитическому вопросу. Интерпретация: в анализе по геополитическому вопросу Mirror Imaging считаем одной из главных угроз, против которых стоит шаг 5 — Red Hat Analysis ([[#9.3 Red Hat Analysis|§9.3]]).
6. **Шаг 6 разбора случившегося события и шаг 4 процедуры прогнозирования развития ситуации (шаги без техники) — малая вероятность.** По Tetlock & Gardner (2015, гл. 6), округлить малую вероятность до нуля значит перейти от угрозы крайне маловероятной, но возможной к угрозе категорически невозможной, и это важно, если последствия маловероятного события достаточно велики. %%src: Tm 1606%% По Pherson & Heuer (2021, гл. 8), словесную вероятность маловероятного события читатели понимают по-разному — от 1 до 25 %, а решающий может прочитать её как меньше 1 %. По ним же, такая разница может решить, заказывать ли дорогие планы на случай или превентивные меры. По ним же, вероятность маловероятного события поэтому лучше давать числом — диапазоном или шансами ([[#10.4 Число вместо слова|§10.4]]). %%src: Pm 5000%% По Heuer (1999, гл. 12), двусмысленность словесной вероятности может особенно мешать при опасностях малой вероятности и большого ущерба, против которых решающий может готовить планы на случай. %%src: Hm 2958–2960%% Интерпретация: поэтому на этих шагах малую субъективную вероятность исхода, у которого большие последствия, не округляют до нуля и дают числом.

При шагах обеих процедур теперь стоят шесть правил. Шаги и правила разбора случившегося события аналитик проходит на случае, а хватит ли для этого рабочей памяти аналитика, не установлено.

Ёмкость рабочей памяти большинства аналитиков — около семи кусков ([[#4.2 Рабочая память|§4.2]]). По Heuer (1999, гл. 3), из-за малой ёмкости рабочей памяти человеку трудно охватить задачу во всей её сложности и удержать в голове сразу все её части. %%src: Hm 835%% По Pherson & Heuer (2021, гл. 7), удержать в рабочей памяти пять–семь гипотез и отметить, как с каждой из них согласуется каждое сведение, большинству аналитиков не под силу. %%src: Pm 3702%% Поскольку матрица ACH на шаге 3 разбора случившегося события и есть такая сверка каждого сведения с каждой гипотезой набора, то при наборе из пяти–семи гипотез большинство аналитиков сверку шага 3 в голове не удержит. Поскольку сверка шага 3 — часть шагов и правил разбора случившегося события, то и все шаги и правила разбора случившегося события при таком наборе большинство аналитиков на случае в голове не удержит. Чем удерживать шаги и правила разбора случившегося события на случае, не сказано.

На каждом шаге процедуры, пройденном на случае, аналитик делает ходы рассуждения к суждению по этому случаю. Записывать на случае ходы рассуждения, сделанные на каждом пройденном шаге процедуры, — значит выносить ходы рассуждения этого аналитика к этому суждению по шагам на внешний носитель этого аналитика, на котором эти ходы видны другим. Следовательно, по определению в [[#6.4 Рассуждение в одной голове и экстернализация|§6.4]] запись ходов рассуждения по пройденным шагам процедуры — экстернализация рассуждения. Та же запись показывает, какие шаги процедуры пройдены. Тот же результат для техник дают Pherson & Heuer (2021, гл. 2, §2.2): пошаговый процесс структурированной аналитической техники выносит рассуждение аналитика наружу ([[#7.1 Структурированная аналитическая техника (SAT)|§7.1]]). %%src: Pm 943%% Выписанные процедуры и правила тоже стоят на внешнем носителе ([[#6.4 Рассуждение в одной голове и экстернализация|§6.4]]), и что идёт дальше и какое правило стоит при шаге, показывают выписанные процедуры и правила. Поскольку на внешнем носителе запись ходов рассуждения по пройденным шагам процедуры и выписанные процедуры и правила держатся без рабочей памяти, то где аналитик в процедуре, на случае показывает запись ходов рассуждения по пройденным шагам процедуры, а не рабочая память. По той же причине ёмкость рабочей памяти не ограничивает число выписанных шагов и правил: на случае их проходят по выписанному, а не держат в голове. По Heuer (1999, гл. 3), вынести задачу из головы на бумагу и есть рекомендуемый приём против малой ёмкости рабочей памяти. %%src: Hm 837%% Сам Heuer, по его словам, справляется с малой ёмкостью рабочей памяти записями вне головы. %%src: Hm 833%% Но выписанные процедуры называют шаги процедуры лишь именами объектов этих шагов, а что такое эти объекты, аналитику нужно помнить, и по чему удерживать сведения об этих объектах, не сказано. По Heuer (1999, гл. 3), в долговременную память лучше переходит то, что связано с уже имеющимися схемами ([[#4.4 Схемы эксперта|§4.4]]). По Heuer (там же), простая модель задачи облегчает переход новых сведений в долговременную память: она даёт структуру, к которой их относят. %%src: Hm 839%% Этот конспект построен как одна цепочка от ведущего вопроса, в которой каждый объект отвечает на нехватку предыдущего шага цепочки ([[#0. Ведущий вопрос и как читать|§0]], [[#15. Цепочка одним взглядом|§15]]). Интерпретация: связи между сведениями об объектах цепочки, усвоенные аналитиком к дате D, — набор связей между сведениями в памяти этого аналитика об области разведывательного анализа, который на эту дату хранится в долговременной памяти этого аналитика. Интерпретация: если по этому набору связей рабочая память этого аналитика удерживает несколько сведений об объектах цепочки как один кусок, то этот набор связей — схема этого аналитика в области разведывательного анализа на эту дату ([[#4.4 Схемы эксперта|§4.4]]), и сведения об объекте, на который ссылается шаг процедуры, связаны в этой схеме со сведениями об объекте, на нехватку которого этот объект отвечает. Интерпретация: тогда сведения об объекте, на который ссылается шаг процедуры, лучше переходят в долговременную память и удерживаются в ней по цепочке. Порядка шагов процедуры цепочка не задаёт; его несут выписанные процедуры. Применение собрано; насколько точны суждения, полученные по этим процедурам, покажет только поток оценок ([[#11.1 Поток оценок|§11.1]]).
