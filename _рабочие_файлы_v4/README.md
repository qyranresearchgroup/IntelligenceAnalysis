# Рабочие файлы перестройки конспекта по методу v4 (режим А)

Служебная папка: нужна только для продолжения работы после паузы. Результат работы — `Матчасть_аналитика.md` и `Матчасть_аналитика — служебный список.md` в корне репозитория; они собираются из файлов этой папки.

- `участки/` — мастер-копии разделов (S00–S16, SAPP = Приложения) со скрытыми ссылками на строки книг `%%src: …%%`; при сборке ссылки уходят в «Карту источников» служебного списка.
- `служебные_списки/` — служебный список по разделам (режим А: построенные и непостроенные выводы, исключённое, расхождения книг, перенесённое из текста).
- `соглашения/` — ядро метода v4 и режим А (`metod_v4.md`, `rezhim_A.md`), соглашения проекта (`SOGL_v4.md`, в том числе решения V10–V11 по всему тексту), основной источник (`main_source.md`), первичные понятия, проект H2/H3 (`DESIGN.md`).
- `сценарии/` — сценарии проверки и правки (рецензенты по 5 линзам, 3 верификатора, правщики; проверка документа целиком; согласование разделов) и сборка (`assemble_v4.py`).
- `рецензии_v4/` — готовые рецензии прерванного (поставленного на паузу) прохода v4: 27 из 90.
- `состояние_работы.md` — журнал проходов и где остановились.
