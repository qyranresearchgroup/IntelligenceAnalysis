# Пилот промптов v4.2 на §2: итоги

**Схема.** Два субагента, Opus 5.5, effort medium.

1. **Писатель** по `Промпт_писателя_v4.2.md` написал §2 с нуля.
   - Входы: три книги, состояние проекта по §0–§1 (реестр, дословные определения, решения V10–V11) и тексты §0–§1.
   - Нынешний §2 ему был закрыт.
2. **Рецензент** по `Промпт_рецензента_v4.2.md`, режим «все линзы», проверил вслепую два текста §2.
   - X — новый, Y — нынешний (после проходов v1–v4 и циклов c1–c6).
   - Какой текст новый, рецензент не знал.
   - На каждый текст — все пять линз и 22–23 места, сверенных с книгами.

**Результат.**

| | high | medium | low |
|---|---|---|---|
| Самопроверка писателя нового §2 (исправлено до рецензии) | 2 | 4 | 11 |
| Рецензия X — новый §2, один проход | 3 | 5 | 5 |
| Рецензия Y — нынешний §2, после ~10 проходов и циклов | 0 | 5 | 4 |
| Для сравнения: самопроверка редактора нынешнего §2 в c4 / c5 / c6 | 0 / 0 / 0 | 3 / 3 / 2 | — |

Два high рецензента по тексту X я сверил с книгой, оба подтверждаются:

- **Hm 1267.** Точность изменилась у 5 гандикаперов из 8: трое хуже, двое лучше. Неизменна только средняя. Текст X выводит «доля верных не меняется» сильнее книги.
- **Hm 1347.** Почти не влияют только сведения о переменных, «that do not in fact have a significant influence». Текст X отбросил это условие.

**Выводы.**

1. **Один проход писателя по v4.2 до уровня отшлифованного текста не доходит.** По high новый текст хуже: 3 против 0. По medium равен: 5 и 5. Все три high — про источники:
   - выпавшее условие книги;
   - фраза P&H, вырванная из контекста операции обмана;
   - выведенный результат сильнее данных книги.

   Самопроверка писателя такие места уже ловила (2 high исправлены), но не все.
2. **Нынешний §2 после всех циклов ещё содержит 5 medium по свежему рецензенту.** Его редактор в c6 насчитал 2. Это снова подтверждает: самопроверка занижает medium, нужен свежий рецензент.
3. **Чего не хватает промпту писателя.**
   - До текста — выписка цитат из книг с их условиями, оговорками («may», «generally», «not necessarily») и контекстом, где фраза стоит в книге. Дальше писать по выписке, а не по памяти о прочитанном. Это рекомендация «ground responses in quotes»; в v4.2 выписка шла только в размышлении.
   - Жёстче: самопроверка до записи. Писатель записал черновик раньше проверки.
   - Отдельная проверка выведенного результата: он совпадает с результатом книги по силе, а не только по смыслу.
4. **Ограничения пилота.**
   - Один раздел и один рецензент.
   - Верификатора не было: часть замечаний (по прошлым проходам 12–19 %) могла бы отпасть.
   - Оба текста рецензент видел в одном разговоре.
   - Effort medium.

**Следующий шаг для проверки гипотезы «писатель + рецензия + верификатор доходят до 0 high/medium быстрее циклов».** Верификатор по рецензии X, затем правка писателем, затем свежий рецензент. Считаем, за сколько кругов новый §2 дойдёт до 0 high и 0 medium.
