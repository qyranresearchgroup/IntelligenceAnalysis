<definitions>
Свойство объекта — то есть состояние этого объекта.
Сведение — для любых аналитика A и даты D — это сообщение о реальности, которое есть у этого аналитика на эту дату.
Содержание любого сведения — это утверждение, которое это сведение сообщает.
Информация — для любых аналитика A и даты D — это все сведения этого аналитика на эту дату, взятые вместе.
Неоднозначное сведение — для любых аналитика A и даты D — это сведение этого аналитика на эту дату, содержание которого верно при двух или более состояниях реальности, при которых верны разные полные ответы на один вопрос, который есть у этого аналитика на эту дату.
Источник сведения — для любых аналитика A, даты D и сведения этого аналитика на эту дату — это тот, от кого это сведение исходит и у кого нет ни одного сообщения от кого-либо другого, которое сообщает содержание этого сведения.
Факт для аналитика — для любых аналитика A и даты — это состояние реальности на эту дату, которое в реальности так и не есть наличие у этого аналитика какого-либо сведения, какой-либо убеждённости или какого-либо умозаключения.
Состояние реальности на любую дату есть факт — то есть это состояние в реальности так на эту дату.
Сообщение источника — для любых аналитика A и даты D — это сообщение, которое есть у этого аналитика на эту дату и исходит от кого-то.
Сведение о факте — для любых аналитика A и даты D — это сведение этого аналитика на эту дату, содержание которого верно при состоянии реальности на какую-либо дату, которое есть факт для этого аналитика на дату этого состояния.
Принять сведение за факт — для любых аналитика A, даты D и сведения этого аналитика на эту дату — это для этого аналитика на эту дату быть убеждённым, что это сведение — сведение о факте.
Вопрос анализа — это вопрос о реальности.
Факт для аналитика относится к вопросу анализа — для любых аналитика A и вопроса анализа Q, — если с состоянием реальности, которое есть этот факт, несовместим хотя бы один полный ответ на этот вопрос анализа.
Решение аналитика о фактах — для любых аналитика A, даты D и вопроса анализа Q — это ответ этого аналитика на эту дату на вопрос, какие из его сведений на эту дату — сведения о фактах, относящихся к этому вопросу анализа, если этот аналитик на эту дату убеждён, что этот ответ верен при состоянии реальности, которое в реальности так.
Аналитик, у которого на дату D есть решение аналитика о фактах, этим решением аналитика о фактах отбирает часть своих сведений на эту дату — то есть выделяет эту часть решением аналитика о фактах.
Аналитик на любую дату принимает утверждение как посылку — то есть на эту дату выводит из этого утверждения заключение какого-либо умозаключения этого аналитика.
Допущение — для любых аналитика A и даты D — это утверждение, которое этот аналитик на эту дату принимает как посылку и которое не есть содержание ни одного из сведений этого аналитика на эту дату.
«Имеющаяся информация» у Heuer — то есть информация аналитика на дату D.
Подвопрос вопроса анализа — для любого вопроса анализа — это вопрос, ответ на который — посылка умозаключения какого-либо аналитика, и заключение этого умозаключения — ответ на этот вопрос анализа.
Выходить за пределы сведений аналитика на дату — это не следовать из одних содержаний его сведений на эту дату.
Ответ построен из сведений и допущений аналитика на дату — для любых аналитика A и даты D, — если этот ответ есть заключение умозаключения этого аналитика на эту дату.
Суждение — для любых аналитика A, даты D и вопроса, который есть вопрос анализа Q или подвопрос этого вопроса анализа, — это ответ на этот вопрос, если этот ответ выходит за пределы сведений этого аналитика на эту дату и построен из сведений и допущений этого аналитика на эту дату.
Категория «суждение» — для любых аналитика A и даты D — это всякое заключение умозаключения этого аналитика на эту дату и всякое утверждение, которое этот аналитик на эту дату принимает как посылку и которое не есть содержание ни одного из сведений этого аналитика на эту дату.
Полная по вопросам информация — для любых аналитика A и даты D — это информация этого аналитика на эту дату, в которой о каждом состоянии реальности, о котором у этого аналитика на эту дату есть вопрос, есть хотя бы одно сведение.
</definitions>
